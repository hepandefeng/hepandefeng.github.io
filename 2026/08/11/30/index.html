新标准日语 第30课 もう11時だから、そろそろ寝よう

⚠️ 单词辨析

  • 予定（よてい） vs 計画（けいかく）：「予定」偏具体的时间安排（几点做什么）；「計画」偏宏观的策划方案（如何实施项目）。
  • 都合がいい vs 便利だ：「都合がいい」指对某人的安排来说方便；「便利だ」指客观上的便利（如交通便利、工具好用）。
  • 楽しみ：既是名词也是形2，意思是“期待的、令人期待的”。例：旅行が楽しみです。（很期待旅行。）

二、语法

语法① 动词的意志形（～よう / ～おう）

意志形表示说话人的意志、决心、打算，相当于中文的“……吧（表示打算做某事）”。

变形规则：

动词类型 变形规则 示例
五段动词（动1） 词尾「う」段 → 「お」段 + う 行く → 行こう
帰る → 帰ろう
休む → 休もう
会う → 会おう
相談するは动3，动1参考：買う→買おう
一段动词（动2） 词尾「る」 → よう 寝る → 寝よう
起きる → 起きよう
見る → 見よう
サ变动词（动3） する → しよう する → しよう
相談する → 相談しよう
予約する → 予約しよう
カ变动词（动3） 来る（くる）→ こよう 来る → 来よう（こよう）

例句：

  • もう11時だから、そろそろ寝よう。（已经11点了，差不多睡吧。）
  • 明日、映画を見よう。（明天看电影吧。）
  • 夏休みに旅行しよう。（暑假去旅行吧。）

💡 用法场景：

  • 自言自语表示决心：よし、頑張ろう！（好，加油吧！）
  • 邀请/提议同伴一起做某事：帰ろうか。（回去吧。）
  • 注意：意志形不能对上级或长辈使用（不够礼貌），应用「～ましょう」替代。

语法② ～ようと思います（表示意志 / 打算）

「～ようと思います」表示说话人自己的意志或打算，相当于中文的“我想……、我打算……”。

接续方式：动词意志形 + と思います

例句：

  • 来年、日本へ行こうと思います。（我打算明年去日本。）
  • もう帰ろうと思います。（我想回去了。）
  • 大学で日本語を勉強しようと思います。（我打算在大学学日语。）

🚨 重要限制：不能用于第三人称（他/她打算做什么）。表示第三人称的打算时，要用「～ようと思っています」或「～ようと言っています」。

✅ 正确：

  • 私は行こうと思います。（我打算去。）
  • 私は勉強しようと思います。（我打算学习。）

❌ 错误：

  • 森さんは行こうと思います。（✗ 不能用「思います」表达别人的意愿。）

语法③ ～ようと思っています（表示持续性的打算 / 计划）

「～ようと思っています」表示打算在一段时间内持续或计划已经考虑了一段时间，相当于中文的“一直在想……、正打算……”。

与「～ようと思います」的区别：

语法 含义 时间感 例句
～ようと思います 当场决定的打算 一时/即时 あっ、寒い。帰ろうと思います。（啊，好冷。我想回去了。）
～ようと思っています 持续考虑的打算 持续/长期 大学卒業後、日本へ行こうと思っています。（大学毕业后，我打算去日本。——一直有这个打算）

例句：

  • 来年、新しい車を買おうと思っています。（我打算明年买新车。——长期计划）
  • 今度の連休、北海道へ行こうと思っています。（这次连休，我打算去北海道。——计划中）
  • 日本語の勉強を続けようと思っています。（我打算继续学日语。——持续打算）

第三人称的用法：

  • 森さんは来月帰国しようと思っています。（森先生下个月打算回国。——转述他人的打算，正确！）
  • 小野さんは転職しようと思っています。（小野女士打算换工作。）

语法④ ～と言っていました（表示转述 / 听说）

「～と言っていました」表示转述别人说过的话，相当于中文的“（某人）说了……、听说……”。

接续方式：各类词简体形 + と言っていました

前面的词类 接续形式 例句
动词简体形 动简 + と言っていました 森さんは行くと言っていました。（森先生说他去。）
一类形容词 形1简 + と言っていました 李さんはおいしいと言っていました。（小李说很好吃。）
二类形容词 形2词干 + だ + と言っていました 部長は無理だと言っていました。（部长说不行。）
名词 名 + だ + と言っていました 田中さんは学生だと言っていました。（田中说他是学生。）

例句：

  • 森さんは明日休むと言っていました。（森先生说明天休息。）
  • 小野さんは京都が好きだと言っていました。（小野女士说喜欢京都。）
  • 李さんは「行きたい」と言っていました。（小李说“想去”。）
  • 天気予報は明日雨が降ると言っていました。（天气预报说明天下雨。）

💡 「～と言っていました」vs「～と言いました」的区别：

语法 含义 使用场景
～と言いました 某人说过了（单纯陈述） 转述过去说过的话，不强调是否还在
～と言っていました 某人说过（强调印象/回忆） 强调“我听到他这么说过”，有记忆留存感

例句对比：

  • 森さんは行くと言いました。（森先生说过要去。——单纯转述）
  • 森さんは行くと言っていました。（森先生说过要去。——我记得他这么说的，强调听说的事实）

三、课文（完整版）

基本课文（句型示例）

  1. もう11時だから、そろそろ寝よう。
    （已经11点了，差不多睡吧。）

  2. 来年、日本へ行こうと思います。
    （我打算明年去日本。）

  3. 大学を卒業したら、日本で働こうと思っています。
    （大学毕业后，我打算在日本工作。）

  4. 森さんは明日休むと言っていました。
    （森先生说明天休息。）

基本课文 会话（A-D）

A

  • もう11時ですね。そろそろ寝ましょうか。
  • そうですね。寝ようと思います。

B

  • 夏休みはどうするつもりですか。
  • 北海道へ行こうと思っています。

C

  • 森さんは、何と言っていましたか。
  • 明日は休むと言っていました。

D

  • 大学を卒業したら、どうしますか。
  • 日本で働こうと思っています。

应用课文（完整长篇对话）

场景：小李、森和小野正在讨论公司年末聚餐和明年的旅行计划。小李和森分别表达了各自的打算，小野则转述了部长之前说过的话。

（午休时间，公司休息室）

  • 李：そろそろ、忘年会の計画を立てようと思っているんですが。
    （我正想着差不多该制定忘年会的计划了。）
  • 森：ああ、そうですね。今年はどこでやりますか。
    （啊，是啊。今年在哪里办呢？）
  • 小野：去年は日本料理店でしたね。
    （去年是在日料店吧。）
  • 李：そうなんです。今年はちょっと違うところにしようと思っています。
    （是的。今年我打算换个不同的地方。）
  • 森：いいですね。例えば、どこですか。
    （好啊。比如说，哪里？）
  • 李：最近、新しい中華料理店がオープンしたんです。そこにしようと思っているんですが、どう思いますか。
    （最近新开了一家中华料理店。我打算去那里，你们觉得怎么样？）
  • 小野：いいですね。でも、予約はもうしましたか。
    （不错啊。不过，预订了吗？）
  • 李：いえ、まだです。これから予約しようと思います。
    （还没。我现在打算去预订。）

（森突然想起来什么）

  • 森：そういえば、部長は今月の末に旅行に行くと言っていましたよ。
    （说起来，部长说过这个月底要去旅行。）
  • 李：えっ、そうなんですか。どこへ行くと言っていましたか。
    （哎，是吗。他说要去哪里？）
  • 森：確か、北海道だと言っていました。
    （我记得他说是北海道。）
  • 小野：ああ、それで先週、部長が「北海道はいいところだ」と話していましたね。
    （啊，难怪上周部长说过“北海道是个好地方”。）
  • 李：じゃあ、部長に北海道の観光情報を聞いてみようと思います。
    （那我打算问问部长北海道的旅游信息。）

（小野转向森）

  • 小野：森さんは、年末はどう過ごそうと思っていますか。
    （森先生年末打算怎么过？）
  • 森：実は、友達と一緒に温泉に行こうと思っています。
    （其实，我打算和朋友一起去泡温泉。）
  • 李：いいですね！どこに行くんですか。
    （不错啊！去哪里？）
  • 森：箱根です。友達が「箱根はとてもきれいだ」と言っていましたから。
    （箱根。因为朋友说“箱根很漂亮”。）
  • 小野：私も行きたいです！
    （我也想去！）
  • 森：じゃあ、一緒に行こうか。
    （那一起去吧。）
  • 小野：本当ですか！楽しみです。
    （真的吗！好期待啊。）
  • 李：いいなあ。私も行こうかな。
    （真好。我也去吧。）
  • 森：みんなで行きましょう！
    （大家一起去吧！）

四、笔记总结

核心重点

本课重点掌握意志形的变形规则以及四种相关表达：

  1. 意志形单独使用（～よう／～おう）——表示“做……吧”（提议/决心）
  2. ～ようと思います——表示“我打算……”（当场决定/个人意志）
  3. ～ようと思っています——表示“我一直在打算……”（持续性计划/第三人称）
  4. ～と言っていました——表示“听说……、某人说……”（转述）

～ようと思う vs ～ようと思っている 对比表

对比项 ～ようと思います ～ようと思っています
中文含义 我想……、我打算……（决定） 我一直在想……、我一直打算……（持续）
时间感 当场决定 / 即时意志 已考虑一段时间 / 持续计划
第三人称 ❌ 不可用 ✅ 可用（转述他人计划）
例句 寒いから、帰ろうと思います。 来年、日本へ行こうと思っています。

～と言いました vs ～と言っていました 对比表

对比项 ～と言いました ～と言っていました
中文含义 说了…… 说过……（我记得/听说）
强调点 陈述“说了”这个事实 强调“听说了”的记忆/印象
例句 森さんは行くと言いました。 森さんは行くと言っていました。

⚠️ 终极易错提醒

  1. 「～ようと思います」不能用于第三人称：❌ 森さんは行こうと思います。 → ✅ 森さんは行こうと思っています。
  2. 意志形的发音：「～おう」不是「～よう」！五段动词是词尾变「お」段+う（如行こう＝いこう），不是「いよう」。唯独一段动词和カ变动词才是「よう／こよう」。
  3. 来る的意志形是「こよう」，不是「きよう」或「くるよう」。
  4. 转述时不要忘记「だ」：二类形容词和名词接「と言っていました」时，要用「だ」连接（✅ 静かだと言っていました ❌ 静かと言っていました）。
  5. 意志形和「～ましょう」的区别：「～ましょう」更礼貌（可对上级用）；意志形较随意（只对同级或下级/自言自语用）。
