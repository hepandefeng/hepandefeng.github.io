7. 常用动词短语与搭配 (Useful Phrases)

短语 释义 例句（简洁）
check in （机场）值机；（酒店）入住 Check in two hours before departure.
check out （酒店）退房 Check out by noon.
take off 起飞 The plane took off on time.
get on / get off 上（车/船）/ 下（车/船） Get off at the next stop.
pull in / pull out （火车）进站 / 出站 The train pulled in late.
run / operate （交通工具）运营 Buses run every 30 minutes.
book / reserve 预订（票/房） Book a flight online.
go sightseeing 去观光 Go sightseeing downtown.
get around 四处走动（交通方式） Get around by subway.
set off / set out 出发，动身 Set off early tomorrow.

备考小贴士：托业的“旅行”场景对 数字、地点和时间 的听力要求极高（Part 3 / Part 4）。务必定格关键信息：

  • 航班号 + 登机口 + 起飞时间（如 Flight BA123 at Gate 8, 10:30 AM）
  • 酒店日期 + 房型 + 房价（如 double room for two nights at $180/night）

同义替换必背：

  • take off = depart = leave（起飞/出发）
  • land = arrive = get in（降落/到达）
  • booking = reservation（预订）
  • fare = fee = charge（费用/票价）
  • vacancy = available room（空房）
  • stopover = layover = transfer（中转停留）

听力重点注意：英式、美式、澳式口音在机场广播中都会出现，平时训练时务必多适应不同口音的数字读法和地名发音（如 Schedule 美式 /ˈskedʒuːl/ 与英式 /ˈʃedjuːl/）。机场广播的语速通常较快，建议提前熟悉固定句式（如 Attention passengers...）。
