新标准日语 第31课 このボタンを押すと、電源が入ります

⚠️ 单词辨析

  • 入る（はいる） vs 入れる（いれる）：「入る」是自动词（电源自己开了），「入れる」是他动词（把某物放进去）。本课使用自动词「入る」。
  • 切る（自动/他动）：表示“切断、关掉”，是他动词。例：電源を切る（关电源）。
  • 上がる vs 下がる：均自动词，表示“上升/下降”，主语是物或数值。例：気温が上がる（气温上升）。
  • 間違える（他动词） vs 間違う（自动词）：「間違える」表示“弄错某事（宾语）”；「間違う」表示“出错（主语出错）”。本课多用「間違える」。

二、语法

语法① ～と（表示恒常条件 / 自然规律 / 习惯）

「～と」表示恒常条件，即“一……就……”或“如果……就……”，用于描述：

  • 自然规律（春になると花が咲く）
  • 机械操作的结果（このボタンを押すと電源が入る）
  • 反复的习惯（起きるとすぐコーヒーを飲む）

接续方式：动词 / 一类形容词 / 二类形容词 / 名词的简体形 + と

词类 接续形式 例句
动词基本形 动简 + と 押すと、電源が入ります。
一类形容词 形1简 + と 寒いと、窓を閉めます。
二类形容词 形2词干 + だ + と 静かだと、よく眠れます。
名词 名词 + だ + と 雨だと、試合は中止です。

例句：

  • このボタンを押すと、電源が入ります。（按这个按钮，电源就会打开。）
  • 春になると、花が咲きます。（一到春天，花就开了。）
  • 私は起きると、すぐコーヒーを飲みます。（我一起床就马上喝咖啡。）
  • 気温が下がると、空気が冷たくなります。（气温一下降，空气就变冷。）

🚨 重要限制：「～と」后面的分句不能使用意志、愿望、命令、请求等表达（即不能用「～たい」「～ましょう」「～てください」「～よう」等）。

✅ 正确（客观事实/自然结果） ❌ 错误（意志/愿望/请求）
春になると、花が咲きます。（自然规律） 春になると、花を見に行きます。（意志）
押すと、電源が入ります。（客观结果） 押すと、電源を入れてください。（请求）
寒くなると、コートを着ます。（习惯） 寒くなると、コートを着ようと思います。（意志）

语法② ～と（表示意外发现）

「～と」还可以表示偶然的发现，即“一做某事，就发现了意想不到的情况”。这时后项往往用过去时（～た）。

例句：

  • ドアを開けると、猫がいました。（一打开门，就发现有一只猫。）
  • 窓を開けると、雪が降っていました。（一打开窗户，发现正在下雪。）
  • 本を読んでいると、友達から電話がかかってきました。（正看书的时候，朋友打来了电话。——这里的「～ていると」表示“正在做某事的时候突然……”）

💡 语法①与语法②的区别：

用法 含义 后项时态 例句
恒常条件 一……就……（规律/习惯） 现在/将来/习惯 春になると、花が咲きます。
意外发现 一……竟然发现…… 过去时（～た） ドアを開けると、猫がいました。

语法③ ～と（表示“如果……”的假设）

「～と」也可以用来表示单纯的假设条件，相当于“如果……的话，就……”。但此时后项仍然是客观结果，不能带主观意志。

例句：

  • この薬を飲むと、よくなります。（如果吃了这个药，就会好转。）
  • あの道をまっすぐ行くと、駅に着きます。（如果沿着那条路直走，就到车站。）
  • 勉強をしないと、試験に合格できません。（如果不学习，就通过不了考试。）

💡 注意：在表示假设时，「～と」比「～ば」「～たら」限制更多（后项不能是主观意志），因此常用于表达客观规则或自然结果。

三、课文（完整版）

基本课文（句型示例）

  1. このボタンを押すと、電源が入ります。
    （按这个按钮，电源就会打开。）

  2. 春になると、花が咲きます。
    （一到春天，花就开了。）

  3. ドアを開けると、猫がいました。
    （一打开门，就发现有一只猫。）

  4. 気温が下がると、空気が冷たくなります。
    （气温一下降，空气就变冷。）

基本课文 会话（A-D）

A

  • このボタンを押すと、どうなりますか。
  • 電源が入ります。

B

  • 春になると、何が咲きますか。
  • 桜が咲きます。

C

  • ドアを開けると、何がありましたか。
  • 猫がいました。

D

  • 気温が下がると、どうなりますか。
  • 寒くなります。

应用课文（完整长篇对话）

场景：小李刚到北京分公司，对办公室里的复印机不太熟悉。森先生正在教她如何使用，两人边操作边聊起了各种“一……就……”的规律和现象。

（办公室里，小李站在复印机前）

  • 李：森さん、このコピー機の使い方を教えてください。
    （森先生，请教我一下这台复印机的使用方法。）
  • 森：いいですよ。まず、この電源ボタンを押すと、電源が入ります。
    （好啊。首先，按这个电源按钮的话，电源就会打开。）
  • 李：なるほど。じゃあ、次はどうしますか。
    （原来如此。那接下来怎么做？）
  • 森：次に、コピーしたい原稿をここに置きます。そして、この緑のボタンを押すと、コピーが始まります。
    （接下来，把要复印的原稿放在这里。然后，按这个绿色按钮，复印就开始了。）

（小李试着操作了一下）

  • 李：あ、本当だ。すごく簡単ですね。
    （啊，真的呢。好简单啊。）
  • 森：でも、間違えたボタンを押すと、エラーが表示されますから、気をつけてください。
    （不过，如果按错了按钮，就会出现错误提示，所以请小心。）
  • 李：はい。ちなみに、この赤いボタンは何ですか。
    （好的。顺便问一下，这个红色按钮是什么？）
  • 森：それはストップボタンです。それを押すと、コピーが止まります。
    （那是停止按钮。按它的话，复印就会停止。）

（小野从旁边走过来）

  • 小野：李さん、コピー機の操作、覚えましたか。
    （小李，复印机的操作记住了吗？）
  • 李：はい、だいたい大丈夫です。でも、まだ自信がありません。
    （嗯，大体上没问题了。不过，还没有自信。）
  • 小野：大丈夫です。何度も使っていると、自然に覚えますよ。
    （没关系。多用几次的话，自然而然就记住了。）
  • 森：そうですね。私も最初は失敗しました。何度も使っていると、慣れます。
    （是啊。我一开始也失败了。多用几次的话，就会习惯的。）

（三个人走到窗边）

  • 小野：あ、見てください。外の桜がもう咲き始めていますね。
    （啊，你们看。外面的樱花已经开始开了呢。）
  • 李：本当ですね。春になると、やっぱり花が咲くのが一番楽しみです。
    （真的呢。一到春天，果然最期待的就是花开了。）
  • 森：日本では、春になると、桜の花がとてもきれいです。
    （在日本，一到春天，樱花就很漂亮。）
  • 李：そうですか。いつか日本の桜を見に行きたいです。
    （是吗。什么时候想去日本看樱花。）

（突然一阵风吹来）

  • 李：あっ、寒くなってきましたね。
    （啊，变冷了呢。）
  • 森：そうですね。気温が下がると、急に寒くなりますね。
    （是啊。气温一下降，就突然变冷了呢。）
  • 小野：窓を開けると、風が入ってきますから、閉めましょうか。
    （一打开窗户，风就吹进来了，关上吧。）
  • 李：そうしましょう。
    （好，关上吧。）

（森关窗时往外看了一眼）

  • 森：あれ？窓の外に何かありますね。
    （哎？窗户外面有什么东西啊。）
  • 李：えっ、何ですか。
    （哎，什么？）
  • 森：ちょっと待ってください。（森打开窗户一看）あっ、猫がいます！
    （等一下。——森打开窗户一看——啊，有只猫！）
  • 小野：本当ですね。窓を開けると、猫がいたんですね。かわいい！
    （真的呢。一打开窗户，竟然有只猫。好可爱！）
  • 森：どうやら、暖かいところを探して来たみたいです。
    （看来是来找暖和的地方了。）
  • 李：気温が下がると、猫も寒いんですね。
    （气温一下降，猫也觉得冷呢。）

四、笔记总结

核心重点

本课重点掌握「～と」的三种主要用法：

  1. 恒常条件/自然规律——春になると花が咲く（一到春天花就开）
  2. 意外发现——ドアを開けると猫がいた（一开门发现猫）
  3. 假设条件——この薬を飲むとよくなる（吃了这个药就会好）

最大原则：后项不能使用意志、愿望、命令、请求等主观表达！

～と与其他条件表达的对比（预习）

语法 后项限制 语气/语感 使用场景
～と ❌ 不能接意志/愿望/命令 客观、自然 自然规律、机械操作、习惯
～ば ⚠️ 有限制 假设性较强 一般假设、建议
～たら ✅ 无限制 口语、随意 各种条件（最万能）
～なら ✅ 无限制 主题性假设 针对对方话题的假设

⚠️ 终极易错提醒

  1. 后项不能接主观表达：

    • ❌ 春になると、花を見に行きましょう。（错误，后项是提议）
    • ✅ 春になると、花が咲きます。（正确，客观事实）

  2. 「～と」前面的动词用基本形，不用「ます形」：

    • ✅ 押すと
    • ❌ 押しますと（错误）

  3. 二类形容词和名词接「～と」时要加「だ」：

    • ✅ 静かだと
    • ❌ 静かと（错误）

  4. 「～と」表示发现时，后项用过去时：

    • ✅ ドアを開けると、猫がいました。
    • ❌ ドアを開けると、猫がいます。（除非是习惯性描述）

  5. 「～ていると」表示“正做某事时突然……”：

    • 例：本を読んでいると、電話がかかってきました。（正在读书时，电话突然打来了。）
