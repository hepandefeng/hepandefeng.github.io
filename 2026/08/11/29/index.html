新标准日语 第29课 電気を消せ

一、单词

教材核心词汇

⚠️ 单词辨析

  • 消す（他动词） vs 消える（自动词）：電気を消す（关灯）/ 電気が消える（灯灭了）。本课命令形主要使用他动词「消す」。
  • 止める（他动词） vs 止まる（自动词）：車を止める（停车）/ 車が止まる（车停了）。
  • 閉める（他动词） vs 閉まる（自动词）：窓を閉める（关窗）/ 窓が閉まる（窗关了）。

二、语法

语法① 动词的命令形（～ろ / ～え）

命令形是日语中语气最强烈的表达方式，用于上司对下属、长辈对晚辈、紧急情况（如火灾、地震）或男性之间的亲密对话。女性一般不使用命令形（显得粗鲁）。

变形规则：

动词类型 变形规则 示例
五段动词（动1） 词尾「う」段 → 「え」段 行く → 行け
消す → 消せ
吸う → 吸え
押す → 押せ
一段动词（动2） 词尾「る」 → 「ろ」（或「よ」） 見る → 見ろ / 見よ
止める → 止めろ
入れる → 入れろ
サ变动词（动3） する → しろ（或「せよ」） する → しろ / せよ
確認する → 確認しろ
カ变动词（动3） 来る（くる）→ こい 来る → 来い（こい）

例句：

  • 電気を消せ！（关灯！）
  • ここに車を止めろ！（把车停在这里！）
  • 早く来い！（快来！）
  • ちゃんと説明しろ！（好好解释！）

🚨 使用场景注意：命令形语气非常强硬，日常会话中通常使用「～てください」「～なさい」等更礼貌的表达。命令形多见于：

  • 紧急情况（火灾时：逃げろ！——快跑！）
  • 男性亲友之间
  • 体育训练、军队等特殊场合
  • 标语、警示牌（如：「触るな」）

语法② ～なさい（表示较为温和的指示、命令）

「～なさい」比命令形语气温和，带有“请你做……”的教导、指示语气。常用于：

  • 老师对学生
  • 父母对孩子
  • 上级对下级（但比命令形礼貌）

接续方式：动词的ます形去掉「ます」 + なさい

动词 ます形 ～なさい形
書く 書きます 書きなさい
見る 見ます 見なさい
する します しなさい
来る 来ます（きます） 来なさい（きなさい）
答える 答えます 答えなさい

例句：

  • 宿題をしなさい。（做作业。）
  • 静かにしなさい。（安静一点。）
  • 質問に答えなさい。（回答问题。）
  • 早く起きなさい。（快起床。）

💡 语气强弱对比（由强到弱）：

命令形（消せ） ＞ ～なさい（消しなさい） ＞ ～てください（消してください） ＞ ～ていただけますか（敬语请求）

语法③ 动词基本形 + な（表示禁止）

表示禁止做某事，语气非常直接、强烈。常用于：

  • 警示牌、标语
  • 上级对下级的严厉禁止
  • 紧急制止

接续方式：动词基本形（辞书形） + な

例句：

  • ここに車を止めるな！（禁止在此停车！）
  • 芝生に入るな！（禁止进入草坪！）
  • タバコを吸うな！（禁止吸烟！）
  • 写真を撮るな！（禁止拍照！）

🚨 「～な」和「～ないで」的区别：

语法 语气 使用场景
～な（禁止） 强硬、直接 警示牌、紧急制止、男性严厉口吻
～ないでください 礼貌、委婉 日常请求、公共场合礼貌用语
～ないで 较随意 口语中熟人之间

例句对比：

  • ✅ ここで吸うな！（别吸了！——强硬）
  • ✅ ここで吸わないでください。（请不要在此吸烟。——礼貌）

语法④ ～て（表示简单的请求/命令）

在口语中，直接用动词的「て形」结尾也可以表示轻松的请求或命令，语气介于「～なさい」和「～てください」之间。多用于：

  • 熟人、朋友之间
  • 轻松的催促

例句：

  • ちょっと待って。（稍等一下。）
  • これ、見て。（你看看这个。）
  • 窓を開けて。（把窗打开。）
  • もう一度言って。（再说一遍。）

💡 注意：「～て」比「～てください」更随意，对长辈或上司不能使用。

三、课文（完整版）

基本课文（句型示例）

  1. 電気を消せ。
    （关灯！）

  2. ここに車を止めるな。
    （禁止在此停车！）

  3. 質問に答えなさい。
    （回答问题！）

  4. ちょっと待って。
    （稍等一下。）

基本课文 会话（A-D）

A

  • 電気を消せ。
  • はい、消します。

B

  • ここに車を止めるな。
  • あっ、すみません。

C

  • 質問に答えなさい。
  • はい、わかりました。

D

  • ちょっと待って。
  • 急いでいるんですが。
  • すぐ終わりますから。

应用课文（完整长篇对话）

场景：下班前，小野和森在办公室收拾东西准备离开。小李看到走廊的灯还亮着，想让森帮忙关掉，却因为着急不小心使用了命令形，随后赶紧纠正。接着他们讨论了公司的节能规则和紧急出口注意事项。

（下班时间，办公室里）

  • 小野：森さん、お先に失礼します。
    （森先生，我先走了。）
  • 森：お疲れ様です。私ももうすぐ帰ります。
    （辛苦了。我也马上回去。）

（小李从走廊走进来）

  • 李：あれ？廊下の電気がまだついていますね。
    （哎？走廊的灯还开着呢。）
  • 森：あ、そうですね。消します。
    （啊，是的。我关掉。）

（小李看着走廊尽头，有点着急）

  • 李：森さん、早く電気を消せ！
    （森先生，快关灯！）
  • 森：えっ？…あっ、はい！（森愣了一下，赶紧去关灯）
    （哎？…啊，好的！）

（小野听到后，笑着对小李说）

  • 小野：李さん、今の言い方はちょっと強かったですね。
    （小李，你刚才的说法有点强硬啊。）
  • 李：あっ、すみません。つい**「消せ」と言ってしまいました。「消してください」**ですね。
    （啊，对不起。我无意中用了“关掉”的命令形。应该说“请关掉”才对。）
  • 森：いいえ、大丈夫です。でも、李さんは時々、命令形を使いますね。
    （没关系。不过，小李你有时会用命令形呢。）
  • 李：ええ、日本語のドラマを見ていると、つい真似をしてしまいます。
    （嗯，看日剧的时候，不知不觉就模仿了。）

（三个人一起走向电梯）

  • 小野：でも、会社では「～なさい」や「～てください」のほうがいいですね。
    （不过，在公司里还是用「～なさい」或「～てください」比较好。）
  • 李：そうですね。例えば、「静かにしなさい」とかですか。
    （是的。比如说「安静一点」之类的吗？）
  • 小野：そうです。あと、緊急の時は命令形を使ってもいいですよ。「逃げろ！」とか。
    （对。还有，紧急的时候也可以用命令形哦。比如“快跑！”之类的。）
  • 森：そうですね。ところで、このビルの非常口はどこですか。
    （是啊。对了，这栋大楼的紧急出口在哪里？）
  • 李：あっちの角にあります。でも、非常口の前には物を置くなという規則があります。
    （在那个拐角处。但是，有规定说“紧急出口前禁止堆放物品”。）
  • 小野：そうなんです。だから、みんな気をつけています。
    （是的。所以大家都很注意。）

（电梯来了）

  • 森：あ、エレベーターが来ました。さあ、乗ろう！（←这里是意志形，第30课内容，先混个脸熟）
    （啊，电梯来了。来吧，上去吧！）
  • 李：はい。今日は命令形をたくさん勉強しましたね。
    （好。今天学了好多命令形呢。）
  • 小野：でも、使う時は気をつけてくださいね。
    （不过，用的时候请多加小心哦。）
  • 森：はい、気をつけます。
    （好的，我会注意的。）

四、笔记总结

核心重点

本课重点掌握命令与禁止的多种表达方式，根据对象和场合选择恰当的语气。

综合命令/禁止表达速查表

语法点 接续方式 语气强度 使用场景 例句
命令形（～ろ/～え） 动词活用 ⭐⭐⭐⭐⭐（最强） 紧急、男性间、军队 消せ / 行け / 来い
～な（禁止） 动基本形 + な ⭐⭐⭐⭐⭐（很强） 警示牌、严厉禁止 止めるな / 吸うな
～なさい Vます形去ます + なさい ⭐⭐⭐（中等） 老师对学生、家长对孩子 書きなさい / しなさい
～て（軽い命令） Vて形 ⭐⭐（较随意） 熟人、朋友之间 待って / 見て
～てください Vて形 + ください ⭐（礼貌） 一般请求（礼貌） 待ってください
～ないでください Vない形 + でください ⭐（礼貌） 礼貌禁止 吸わないでください

⚠️ 终极易错提醒

  1. 对上司/长辈绝对不能用命令形！❌ 部長、これを見ろ！（非常失礼） ✅ 部長、これを見てください。
  2. 「～な」前面必须是基本形，不是「ない形」。 ✅ 吸うな（别吸） ❌ 吸わないな（错误）。
  3. 「～なさい」接「ます形」去「ます」，不是接「基本形」。 ✅ 書きなさい ❌ 書くなさい（错误，变成了禁止形）。
  4. 女性在正式场合要避免使用命令形，多用「～てください」或「～ませんか」等委婉表达。
  5. **「来い（こい）」**读音特殊，不是「きい」或「くるい」，务必记住。
