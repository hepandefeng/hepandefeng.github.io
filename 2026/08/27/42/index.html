新标准日语 第42课 私は犬に足を噛まれました

⚠️ 单词辨析

  • 噛む（かむ） vs 噛まれる（かまれる）：「噛む」是“咬”（主动）；「噛まれる」是“被咬”（被动）。注意变形：五段动词「噛む」的被动形是「噛まれる」，不是「噛ませる」（那是使役形）。
  • 笑う（わらう） vs 笑われる（わらわれる）：「笑う」是“笑”（主动）；「笑われる」是“被笑”（被嘲笑）。注意发音区别。
  • 驚く（おどろく） vs 驚かせる（おどろかせる） vs 驚かれる（おどろかれる）：
    • 驚く：吃惊（自动词）
    • 驚かせる：让某人吃惊（使役形）
    • 驚かれる：被某人惊吓（被动形）
  • 盗む（ぬすむ） vs 盗まれる（ぬすまれる）：「盗む」是“偷”（主动）；「盗まれる」是“被偷”（被动）。

二、语法

语法① 动词的被动形（～られる / ～れる）

被动形表示主语是动作的承受者，相当于中文的“被……”“遭……”。

变形规则：

动词类型 变形规则 示例
五段动词（动1） 词尾「う」段 → 「あ」段 + れる 噛む → 噛まれる
踏む → 踏まれる
押す → 押される
取る → 取られる
一段动词（动2） 词尾「る」 → られる 褒める → 褒められる
食べる → 食べられる
見る → 見られる
サ变动词（动3） する → される する → される
勉強する → 勉強される
連絡する → 連絡される
カ变动词（动3） 来る（くる）→ こられる 来る → 来られる（こられる）

⚠️ 注意：五段动词的被动形与一段动词的可能形形式相同，需要根据上下文判断。

动词 被动形 可能形
書く 書かれる（被写） 書ける（能写）
読む 読まれる（被读） 読める（能读）
見る 見られる（被看） 見られる（能看）——形式相同！

语法② 被动句的基本句型

句型1：直接被动（动作的直接承受者做主语）

句型 例句
私は + 人に + 动被动形 私は犬に足を噛まれました。（我被狗咬了脚。）
物が + 人に + 动被动形 この本は多くの人に読まれています。（这本书被很多人读。）

例句：

  • 私は先生に褒められました。（我被老师表扬了。）
  • 彼は友達に笑われました。（他被朋友笑了。）
  • この曲は若い人にたくさん聞かれています。（这首歌被很多年轻人听。）

句型2：被动句的间接对象（受害被动/干扰被动）

当动作的承受者身体的一部分或所有物受到动作影响时，用「～に～を」结构：

句型 例句
私は + 人に + 身体/所有物を + 动被动形 私は犬に足を噛まれました。（我被狗咬了脚。）

例句：

  • 私は隣の人に足を踏まれました。（我被旁边的人踩了脚。）
  • 私は電車の中で足を踏まれました。（我在电车里被踩了脚。）
  • 彼は泥棒に財布を盗まれました。（他被小偷偷了钱包。）
  • 私は後ろの人に押されました。（我被后面的人推了。）

句型3：间接受害被动（由于他人的行为而遭受麻烦）

当说话人间接受到他人行为的负面影响时使用。主语往往不是动作的直接对象，但受到了牵连。

例句：

  • 私は隣の人にたばこを吸われました。（我被旁边的人抽烟了。——他抽烟，我受害）
  • 私は子供に泣かれました。（我被孩子哭了。——孩子哭，我受害）
  • 私は雨に降られました。（我被雨淋了。——下雨，我受害）
  • 私は電車の中で傘を忘れられました。（有人在电车里忘了伞，我受害了。——不自然，更常见的是「忘れ物をされた」）

💡 被动句的类型总结：

类型 结构 例句
直接被动 私は + 人に + 动被动形 私は先生に褒められた
所有物被动 私は + 人に + 物を + 动被动形 私は犬に足を噛まれた
受害被动 私は + 人に + 动被动形（自动词） 私は子供に泣かれた

三、课文（完整版）

基本课文（句型示例）

  1. 私は犬に足を噛まれました。
    （我被狗咬了脚。）

  2. 私は先生に褒められました。
    （我被老师表扬了。）

  3. 私は隣の人に足を踏まれました。
    （我被旁边的人踩了脚。）

  4. この本は多くの人に読まれています。
    （这本书被很多人读。）

基本课文 会话（A-D）

A

  • どうしたんですか。足が痛いようですね。
  • ええ、犬に噛まれました。

B

  • 試験はどうでしたか。
  • 先生に褒められました。

C

  • 足が痛そうですね。
  • 電車の中で隣の人に足を踏まれました。

D

  • この本はよく売れていますね。
  • ええ、多くの人に読まれていますから。

应用课文（完整长篇对话）

场景：小李在通勤电车里被踩了脚，还差点被偷钱包。森和小野听了她的经历，分享了自己曾经的遭遇。三个人聊起了各种“被……”的经历。

（公司休息室，午休时间）

  • 李：今朝の通勤電車はすごく混んでいて、大変でした。
    （今天早上的通勤电车非常拥挤，太辛苦了。）
  • 小野：そうなんですか。何かありましたか。
    （是吗。发生了什么事吗？）
  • 李：ええ、電車の中で足を踏まれました。
    （嗯，在电车里被踩了脚。）
  • 森：それは大変でしたね。
    （那真是辛苦啊。）

（小李继续讲述）

  • 李：それだけじゃなくて、バッグも開けられそうになりました。
    （不只是这样，包还差点被打开。）
  • 小野：えっ！もしかして、スリですか。
    （哎！莫非是小偷？）
  • 李：はい、多分そうです。バッグのファスナーが少し開けられていました。
    （是的，大概是的。包的拉链被拉开了一点。）
  • 森：それは危なかったですね。財布は大丈夫でしたか。
    （那太危险了。钱包没事吧？）
  • 李：はい、盗まれませんでした。すぐに気がつきましたから。
    （嗯，没被偷。因为我马上就发现了。）

（小野松了一口气）

  • 小野：よかったですね。私も昔、電車で財布をすられたことがあります。
    （太好了。我以前也在电车上被偷过钱包。）
  • 李：えっ、そうなんですか。
    （哎，是吗？）
  • 小野：ええ。その時は、お金もカードも全部取られてしまいました。
    （嗯。那时，钱和卡都被拿走了。）
  • 森：それはひどいですね。
    （那太过分了。）

（森分享自己的经历）

  • 森：私は先週、バスで後ろの人に押されました。
    （我上周在公交车上被后面的人推了。）
  • 李：それで、どうなりましたか。
    （然后怎么样了？）
  • 森：前に倒れそうになって、隣の人に足を踏まれてしまいました。
    （差点往前摔倒，结果踩到了旁边人的脚。——这里「踏まれてしまいました」是被动+完了，表示发生了坏事）
  • 小野：それはお互いに大変でしたね。
    （那双方都很辛苦啊。）

（小李若有所思）

  • 李：日本の電車はいつもこんなに混んでいるんですか。
    （日本的电车总是这么拥挤吗？）
  • 森：そうですね。特に朝と夕方は満員電車と言われるほど混んでいます。
    （是啊。特别是早上和傍晚，拥挤到被称为“满员电车”的程度。）
  • 小野：そうなんです。だから、押されることもよくあります。
    （是的。所以也经常被推挤。）
  • 李：慣れるまで、ちょっと怖いですね。
    （在习惯之前，有点可怕呢。）

（这时科长走过来）

  • 課長：李さん、さっき部長に呼ばれていましたよ。
    （小李，刚才部长叫你哦。）
  • 李：えっ、私ですか。何か用事でしょうか。
    （哎，叫我吗。有什么事呢？）
  • 課長：さあ、よく分かりませんが、早く行ったほうがいいですよ。
    （嗯，不太清楚，不过最好早点去。）
  • 李：はい、行かれてきます。（←这里「行かれて」是敬语的表现，而非被动，第43课内容）
    （好的，我去了就来。）

（小李走后）

  • 森：李さん、今日はいろいろなことに巻き込まれましたね。
    （小李今天被卷入了各种事情呢。）
  • 小野：そうですね。でも、ちゃんと注意されていたから、大丈夫でしたね。
    （是啊。不过，因为她有好好注意，所以没事呢。）

（这时小李回来了）

  • 李：課長、部長は報告書を読まれていました。（这里「読まれていました」是被动态，表示“正在被人阅读”）
    （科长，部长正在阅读报告书。）
  • 課長：そうですか。じゃあ、後でまた呼ばれるかもしれませんね。
    （是吗。那待会儿可能还会被叫吧。）
  • 小野：でも、報告書が読まれているということは、いいことですよ。
    （不过，报告书被阅读这件事，是好事哦。）
  • 森：そうです。評価されるチャンスですからね。
    （是的。因为是被评价的机会。）
  • 李：そうですね。頑張ります！
    （是啊。我会加油的！）

四、笔记总结

核心重点

本课重点掌握动词被动形的变形规则，以及被动句的三种主要类型。

被动形变形速查表

动词类型 原形 ます形 被动形
五段（动1） 噛む 噛みます 噛まれる
踏む 踏みます 踏まれる
押す 押します 押される
取る 取ります 取られる
読む 読みます 読まれる
書く 書きます 書かれる
話す 話します 話される
盗む 盗みます 盗まれる
一段（动2） 褒める 褒めます 褒められる
食べる 食べます 食べられる
見る 見ます 見られる
サ变（动3） する します される
勉強する 勉強します 勉強される
カ变（动3） 来る 来ます 来られる（こられる）

被动句三种类型对比表

类型 结构 例句 中文
直接被动 私は + 人に + 动被动形 私は先生に褒められた 我被老师表扬了
所有物被动 私は + 人に + 物を + 动被动形 私は犬に足を噛まれた 我被狗咬了脚
受害被动 私は + 人に + 动被动形（自动词） 私は子供に泣かれた 我被孩子哭了（孩子哭，我受害）

被动句的助词使用规则

助词 用法 例句
に 表示动作主体（谁做的） 先生に褒められた
を 表示被施加动作的身体部位/所有物 足を噛まれた
が 表示被动句的主语（承受者） 私が先生に褒められた

⚠️ 终极易错提醒

  1. 五段动词被动形不是加「られる」：

    • ✅ 噛まれる（噛む→噛まれる）
    • ❌ 噛まられる（错误）

  2. 「する」的被动形是「される」，不是「させられる」：

    • ✅ 勉強される（被学习）
    • ❌ 勉強させられる（被迫学习——使役被动，第43课内容）

  3. 「来る」的被动形是「こられる」，不是「きられる」：

    • ✅ 来られる（こられる）
    • ❌ 来られる（きられる）（错误读音）

  4. 一段动词的被动形与可能形形式相同：

    • 見られる：可能形（能看见）/ 被动形（被看见）
    • 食べられる：可能形（能吃）/ 被动形（被吃）
    • 需要根据上下文判断！

  5. 受害被动（自动词被动）的动词是自动词：

    • 自动词一般没有被动形，但受害被动中可以使用：
    • 泣く（自动词）→ 泣かれる（被哭——别人哭，我受害）
    • 降る（自动词）→ 降られる（被下雨——下雨，我受害）

  6. 「～に～を」结构的语序：

    • ✅ 私は犬に足を噛まれました。
    • ❌ 私は足を犬に噛まれました。（虽可理解，但语序不自然）

  7. 被动句与主动句的转换：

    • 主动：犬が私の足を噛んだ。（狗咬了脚。）
    • 被动：私は犬に足を噛まれた。（我被狗咬了脚。）
    • 注意：主动句的宾语（足）在被动句中仍用「を」！
