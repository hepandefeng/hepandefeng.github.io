新标准日语 第46课 ここに車を止めてはいけません

⚠️ 单词辨析

  • 止める（とめる・他動詞） vs 止まる（とまる・自動詞）：「止める」表示“使……停止”（人为）；「止まる」表示“停止”（自然）。本课「止めてはいけません」使用他动词「止める」。
  • 吸う（すう） vs 吹く（ふく）：「吸う」表示“吸（烟）、吸入”；「吹く」表示“吹（风）”。注意区分。
  • 守る（まもる） vs 従う（したがう）：「守る」表示“遵守（规则、约定）”；「従う」表示“遵从（命令、指示）”。
  • 違反（いはん） vs 犯罪（はんざい）：「違反」指“违反（规则、法律）”（较轻）；「犯罪」指“犯罪”（较重）。

二、语法

语法① ～てはいけません（表示禁止）

「～てはいけません」表示禁止做某事，相当于中文的“不可以……”“不准……”。

接续方式：动词て形 + はいけません

例句：

  • ここに車を止めてはいけません。（这里不可以停车。）
  • 図書館で話してはいけません。（图书馆里不可以说话。）
  • タバコを吸ってはいけません。（不可以吸烟。）
  • お酒を飲んで運転してはいけません。（不可以酒后驾驶。）

💡 口语缩略：

  • ～てはいけません → ～ちゃいけません（更口语化）
  • 例：話しちゃいけません。（不可以说话。）

💡 对上级/长辈的礼貌说法：

  • ～ないでください（请不要……）——更礼貌
  • 例：ここに車を止めないでください。（请不要在这里停车。）

语气对比：

语法 含义 语感
～てはいけません 不可以…… 禁止（较强）
～ないでください 请不要…… 礼貌禁止
～てはだめです ……不行 禁止（口语化）
～な 不准…… 强烈禁止（男性）

语法② ～なくてもいいです（表示不必 / 无需）

「～なくてもいいです」表示不做某事也可以，相当于中文的“不……也可以”“不必……”。

接续方式：动词ない形去掉「い」+ くてもいいです

变形步骤：

  1. 动词 → ない形（简体否定形）
  2. ない形 → 去掉词尾「い」→ なく
    • てもいいです
动词 ない形 ～なくてもいいです
行く 行かない 行かなくてもいいです（不去也可以）
食べる 食べない 食べなくてもいいです（不吃也可以）
する しない しなくてもいいです（不做也可以）
来る 来ない（こない） 来なくてもいいです（こなくてもいいです）（不来也可以）

例句：

  • 明日は来なくてもいいです。（明天不来也可以。）
  • 全部食べなくてもいいですよ。（不用全吃完也可以哦。）
  • この仕事は急がなくてもいいです。（这项工作不用急也可以。）
  • ネクタイをしなくてもいいです。（不打领带也可以。）

💡 「～てもいいです」（许可）与「～なくてもいいです」（不必）的对比：

语法 含义 例句
～てもいいです 可以做……（许可） ここに座ってもいいです。（可以坐在这里。）
～なくてもいいです 不……也可以（不必） ここに座らなくてもいいです。（不坐在这里也可以。）

语法③ ～とか～とか（表示列举）

「～とか～とか」表示列举多个有代表性的事例，相当于中文的“……啦……啦”。

接续方式：各类词简体形 + とか

词类 接续形式 示例
动词（基本形/た形） 动简 + とか 食べるとか、飲むとか
名词 名词 + とか コーヒーとか、紅茶とか

例句：

  • 夏休みに、海に行くとか、山に行くとか、いろいろ考えています。（暑假，去海边啦，去山里啦，在考虑各种事情。）
  • この店では、コーヒーとか紅茶とか、いろいろな飲み物があります。（这家店有咖啡啦红茶啦等各种饮料。）
  • 彼はサッカーとかテニスとか、スポーツが好きです。（他喜欢足球啦网球啦等运动。）
  • 休みの日は、本を読むとか、映画を見るとかしています。（休息日，看看书啦看电影啦。）

💡 「～とか～とか」vs「～たり～たり」的区别：

语法 接续 含义 例句
～たり～たり 动词た形 + り 列举动作（时而……时而……） 食べたり飲んだりする
～とか～とか 各类词简体 + とか 列举例子（……啦……啦） コーヒーとか紅茶とか

语法④ ～てはいけません vs ～なくてもいいです 综合对比

语法 含义 接续 例句
～てはいけません 不可以……（禁止） て形 + はいけません 止めてはいけません
～なくてもいいです 不……也可以（不必） ない形去掉い + くてもいい 止めなくてもいいです

三、课文（完整版）

基本课文（句型示例）

  1. ここに車を止めてはいけません。
    （这里不可以停车。）

  2. 明日は来なくてもいいです。
    （明天不来也可以。）

  3. この店では、コーヒーとか紅茶とか、いろいろな飲み物があります。
    （这家店有咖啡啦红茶啦等各种饮料。）

  4. タバコを吸ってはいけません。
    （不可以吸烟。）

基本课文 会话（A-D）

A

  • ここに車を止めてもいいですか。
  • いいえ、止めてはいけません。

B

  • 明日、来なければなりませんか。
  • いいえ、来なくてもいいです。

C

  • この店には何がありますか。
  • コーヒーとか紅茶とか、いろいろな飲み物があります。

D

  • ここでタバコを吸ってもいいですか。
  • いいえ、吸ってはいけません。

应用课文（完整长篇对话）

场景：小李搬了新家，森和小野来帮她搬家。小野提醒她注意公寓的垃圾分类规则和禁止事项，还告诉她一些生活上的注意事项。大家边整理边聊天。

（小李的新公寓前）

  • 李：ここが私の新しいアパートです。
    （这里是我的新公寓。）
  • 森：いい場所ですね。駅からも近いし、静かそうですね。（←样态「そうです」）
    （好地方啊。离车站也近，看起来也很安静。）
  • 小野：そうですね。でも、マンションにはいろいろなルールがありますから、注意しなければなりませんね。
    （是啊。不过，公寓有各种各样的规则，必须注意呢。）

（进到房间里）

  • 小野：このアパートは、ペットを飼ってはいけませんか。
    （这个公寓不可以养宠物吗？）
  • 李：はい。飼ってはいけません。でも、私はペットはいないので、大丈夫です。
    （是的。不可以养。不过，我没有宠物，所以没关系。）
  • 森：それならいいですね。ゴミの出し方はどうですか。
    （那还好。垃圾的扔法怎么样？）
  • 李：曜日によって、出すゴミが違います。
    （根据星期几，扔的垃圾不同。）

（小野拿出手机查看）

  • 小野：この辺は、プラスチックゴミとか、缶とかビンとか、分別が厳しいらしいですよ。
    （听说这一带，塑料垃圾啦，罐子啦瓶子啦，分类很严格。）
  • 李：そうなんですか。しっかり覚えなければなりませんね。
    （是吗。必须好好记住啊。）
  • 森：でも、間違っても大丈夫ですよ。最初はみんな間違えますから。
    （不过，弄错了也没关系。因为一开始大家都会弄错。）

（小李拿出饮料）

  • 李：コーヒーとかお茶とか、何か飲みますか。
    （咖啡啦茶啦，你们喝什么吗？）
  • 森：ありがとうございます。コーヒーをいただきます。
    （谢谢。我喝咖啡。）
  • 小野：私はお茶がいいです。
    （我喝茶就好。）

（一边休息一边聊天）

  • 小野：そういえば、このアパートの駐車場はどこですか。
    （话说回来，这个公寓的停车场在哪里？）
  • 李：あ、裏にあります。でも、駐車場以外に止めてはいけません。
    （啊，在后面。不过，停车场以外的地方不可以停车。）
  • 森：それは大切なルールですね。違反すると、罰金を取られるかもしれません。
    （那是重要的规则呢。如果违反的话，可能会被罚款。）
  • 李：そうなんです。大家さんにも注意されました。（←被动形「注意されました」）
    （是的。也被房东提醒了。）

（整理结束后）

  • 森：今日は手伝ってくれて、ありがとうございました。
    （今天谢谢你们帮忙。）
  • 小野：いいえ、楽しかったです。新生活、無理をしなくてもいいですから、ゆっくり慣れてくださいね。
    （不客气，很开心。新生活，不用勉强，请慢慢习惯哦。）
  • 李：はい。分からないことがあったら、また森さんとか小野さんとかに聞きます。
    （好的。如果有不明白的事，我再问森先生啦小野女士啦。）
  • 森：いつでも連絡してくださいね。
    （随时联系哦。）

（小野临走前再次提醒）

  • 小野：そうだ、夜遅くに騒いではいけませんよ。近所に迷惑になりますから。
    （对了，深夜不可以吵闹哦。因为会给邻居添麻烦。）
  • 李：はい、気をつけます。音楽もあまり大きくしてはいけませんね。
    （好的，我会注意的。音乐也不能开太大吧。）
  • 森：そうです。でも、静かにしなくてもいい場合もありますよ。昼間なら大丈夫です。
    （是的。不过，也有不必那么安静的时候哦。白天的话没问题。）
  • 小野：そうですね。ルールを守って、楽しい新生活を送ってください。
    （是啊。遵守规则，度过愉快的新生活吧。）
  • 李：ありがとうございます！頑張ります。
    （谢谢！我会加油的！）

四、笔记总结

核心重点

本课重点掌握三个表达：

  1. 「～てはいけません」——表示禁止（不可以……）
  2. 「～なくてもいいです」——表示不必（不……也可以）
  3. 「～とか～とか」——表示列举（……啦……啦）

～てはいけません 用法速查表

形式 含义 例句
肯定 不可以……（禁止） 車を止めてはいけません
口语缩略 不准……（口语） 止めちゃいけません

～なくてもいいです 接续速查表

动词 ない形 ～なくてもいいです
行く（いく） 行かない 行かなくてもいい
来る（くる） 来ない（こない） 来なくてもいい（こなくてもいい）
する しない しなくてもいい
食べる 食べない 食べなくてもいい
飲む（のむ） 飲まない 飲まなくてもいい

～とか～とか 用法速查表

形式 含义 例句
名词 + とか ……啦……啦（列举事物） コーヒーとか紅茶とか
动词基本形 + とか ……啦……啦（列举动作） 食べるとか飲むとか

本课三大语法核心对比

语法 含义 接续 例句
～てはいけません 不可以……（禁止） て形 + はいけません 止めてはいけません
～なくてもいいです 不……也可以（不必） ない形去掉い + くてもいい 止めなくてもいいです
～とか～とか ……啦……啦（列举） 各类词简体 + とか コーヒーとか紅茶とか

许可/禁止/必要/不必 综合对比

语法 含义 接续 例句
～てもいいです 可以做……（许可） て形 + もいい 止めてもいい
～てはいけません 不可以……（禁止） て形 + はいけない 止めてはいけない
～なければなりません 必须做……（必要） ない形去掉い + ければならない 止めなければならない
～なくてもいいです 不……也可以（不必） ない形去掉い + くてもいい 止めなくてもいい

⚠️ 终极易错提醒

  1. 「～てはいけません」用的是て形 + はいけません，不是「～てはなりません」：

    • ✅ 止めてはいけません
    • ❌ 止めてはなりません（虽然也有此说法，但不常用）

  2. 「～なくてもいいです」的变形要准确：

    • ✅ 行かなくてもいいです（行かない→行かなく）
    • ❌ 行かないでもいいです（错误）
    • ✅ 食べなくてもいいです（食べない→食べなく）
    • ❌ 食べないでもいいです（错误）

  3. 「～てはいけません」的口语缩略「ちゃいけません」：

    • ✅ 止めちゃいけません
    • ✅ 吸っちゃいけません
    • 注意：五段动词的音便规则与て形相同

  4. 「～なくてもいいです」和「～なければなりません」对比记忆：

    • ～なくてもいい = 不……也可以（不必）
    • ～なければならない = 必须……（必要）
    • 二者是反义关系，但变形相似，注意区分！

  5. 「～とか～とか」不能用于列举唯一的例子：

    • ✅ コーヒーとか紅茶とか（至少列举两个例子）
    • ❌ コーヒーとか（只列举一个时不自然）

  6. 「～てはいけません」的礼貌替代：

    • 对上级/长辈：～ないでください（请不要……）
    • 对同级/下级：～てはいけません（不可以……）
    • 警告标识：～禁止（如：駐車禁止）
