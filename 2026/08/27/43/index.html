新标准日语 第43课 私は友達にコーヒーを飲ませられました

一、单词

⚠️ 单词辨析

  • 嫌（いや） vs 嫌がる（いやがる）：「嫌」是二类形容词，表示“讨厌的”（状态）；「嫌がる」是动词，表示“表现出讨厌的样子”（行为）。例：私はそれが嫌です。（我讨厌那个。）/ 彼はそれを嫌がっています。（他讨厌那个的样子。）
  • 困る（こまる） vs 迷惑する（めいわくする）：「困る」表示“为难、不好办”；「迷惑する」表示“给人添麻烦、受到困扰”。「迷惑」更强调对他人的负面影响。
  • 仕方ない（しかたない）：表示“没办法、无可奈何”，常用于安慰或表达无奈。口语中常说「しょうがない」。
  • 我慢する（がまんする）：表示“忍耐、忍受”，常用于描述被迫做某事时的心理状态。

二、语法

语法① 动词的使役被动形（～させられる / ～される）

使役被动形表示被迫/不情愿地做某事，相当于中文的“被迫……”“不得不……”。

变形规则：

动词类型 变形规则 示例
五段动词（动1） 使役形（～せる）的「る」→「られる」
或：词尾「う」段→「あ」段+される		 飲む → 飲ませられる / 飲まされる
行く → 行かせられる / 行かされる
待つ → 待たせられる / 待たされる
働く → 働かせられる / 働かされる
一段动词（动2） 使役形（～させる）的「る」→「られる」 食べる → 食べさせられる
見る → 見させられる
教える → 教えさせられる
サ变动词（动3） する → させられる する → させられる
勉強する → 勉強させられる
残業する → 残業させられる
カ变动词（动3） 来る→来させられる（こさせられる） 来る → 来させられる

⚠️ 五段动词有两种省略形：

  • 完整形：飲ませられる（正式、书面）
  • 省略形：飲まされる（口语常用，更简洁）
  • 两种都正确，口语多用省略形。

例句：

  • 私は友達にコーヒーを飲ませられました。（我被朋友迫喝了咖啡。）
  • 子供の時、母に野菜を食べさせられました。（小时候，被妈妈迫吃了蔬菜。）
  • 毎日、残業をさせられています。（每天被迫加班。）
  • 雨の中で待たされました。（被迫在雨中等待。）

语法② 使役被动句的句型结构

句型1：他动词的使役被动（被迫做某事）

句型 例句
私は + 人に + 物を + 使役被动形 私は友達にコーヒーを飲ませられました。

例句：

  • 私は母に野菜を食べさせられました。（我被妈妈逼着吃了蔬菜。）
  • 彼は先生に宿題をやらされました。（他被老师逼着做了作业。——「やる」→「やらされる」）
  • 私は先輩に酒を飲まされました。（我被前辈逼着喝了酒。）

句型2：自动词的使役被动（被迫做某个动作）

自动词使役被动表示被迫进行某个动作，主语是动作的执行者（但动作不是自愿的）。

句型 例句
私は + 人に + 使役被动形 私は雨の中で待たされました。

例句：

  • 私は上司に大阪へ行かされました。（我被上司逼着去了大阪。）
  • 彼は先輩に帰らされました。（他被前辈逼着回去了。）
  • 私は課長に残業させられました。（我被科长逼着加了班。）

语法③ 使役被动形 vs 使役形 vs 被动形 对比

动词形态 含义 例句
基本形 做某事 コーヒーを飲みます。（喝咖啡。）
使役形 让某人做某事 友達にコーヒーを飲ませました。（让朋友喝了咖啡。）
被动形 被…… 友達にコーヒーを飲まれました。（咖啡被朋友喝了。）
使役被动形 被迫做某事 友達にコーヒーを飲ませられました。（被迫喝了咖啡。）

⚠️ 注意：使役被动形的主语是被迫做某事的人，不是动作的发出者。

语法④ ～させてください（复习）

「～させてください」表示请求对方允许自己做某事，在使役被动的基础上，反过来用于礼貌请求。

例句：

  • ちょっと休ませてください。（请让我休息一下。）
  • 私にもやらせてください。（请让我也做。）
  • 一度考えさせてください。（请让我考虑一下。）

三、课文（完整版）

基本课文（句型示例）

  1. 私は友達にコーヒーを飲ませられました。
    （我被朋友迫喝了咖啡。）

  2. 子供の時、母に野菜を食べさせられました。
    （小时候，被妈妈迫吃了蔬菜。）

  3. 毎日、残業をさせられています。
    （每天被迫加班。）

  4. 雨の中で待たされました。
    （被迫在雨中等待。）

基本课文 会话（A-D）

A

  • どうして、そんなにまずそうな顔をしているんですか。
  • 友達にコーヒーを飲ませられました。

B

  • 子供の時、何を食べさせられましたか。
  • 母に野菜を食べさせられました。

C

  • 最近、残業が多いですね。
  • ええ、毎日残業させられています。

D

  • なぜ、そんなに遅くなったんですか。
  • 雨の中で待たされました。

应用课文（完整长篇对话）

场景：小李在酒会上被前辈不停地劝酒，喝了好多。第二天上班时，她觉得很不舒服，向森和小野抱怨。小野也分享了自己被迫加班的经历。

（公司休息室，小李脸色不好）

  • 森：李さん、顔色が悪いですね。大丈夫ですか。
    （小李，你脸色不好啊。没事吧？）
  • 李：すみません。昨日、先輩にお酒を飲ませられて、今日はまだ頭が痛いんです。
    （对不起。昨天被前辈迫喝了酒，今天头还在痛。）
  • 小野：それは大変でしたね。どのくらい飲まされましたか。
    （那太辛苦了。被喝了多少？）

（小李苦笑着）

  • 李：ビールを3杯、日本酒を2杯も飲ませられました。
    （被喝了3杯啤酒，还被喝了2杯日本酒。）
  • 森：それはひどい。無理やり飲ませるのはよくないですね。
    （那太过分了。硬逼人喝酒可不好啊。）
  • 李：でも、先輩が「飲め」と言うので、断れませんでした。
    （不过，因为前辈说“喝吧”，我没法拒绝。）

（小野深有同感）

  • 小野：私も先週、上司に残業させられました。
    （我上周也被上司逼着加班了。）
  • 李：えっ、小野さんもですか。
    （哎，小野女士也是吗？）
  • 小野：ええ。土曜日も出勤させられて、日曜日は一日中寝ていました。
    （嗯。周六也被迫出勤了，周日睡了一整天。）
  • 森：それはお気の毒に。最近、仕事が忙しいですからね。
    （那太可怜了。因为最近工作很忙啊。）

（小李叹气）

  • 李：私は日本に来てから、いろいろなことをさせられました。
    （我来日本之后，被迫做了各种事情。）
  • 森：例えば、何をさせられましたか**。
    （比如说，被做了什么？）
  • 李：社内のイベントを企画させられたり、日本語のスピーチをさせられたりしました。
    （被要求策划公司内部的活动啦，被要求做日语演讲啦。）
  • 小野：でも、それはいい経験になりましたね。
    （不过，那成为了好的经验吧。）
  • 李：そうですね。今思えば、させられたからこそ、成長できたと思います。
    （是啊。现在想想，正因为被迫做了，才能成长吧。）

（森拿出手机）

  • 森：そう言えば、私は大学生の時、先輩に毎日練習させられました。
    （说起来，我大学的时候，被前辈迫每天练习。）
  • 小野：何の練習ですか。
    （什么练习？）
  • 森：テニスです。毎朝6時に起きて、2時間走らされました**。
    （网球。每天早上6点起床，被迫跑了2个小时。）
  • 李：それは大変でしたね。
    （那真是辛苦啊。）
  • 森：ええ。でも、そのおかげで、強くなりましたよ。
    （是啊。不过，多亏了那个，我变强了。）

（小野看看手表）

  • 小野：あ、もうすぐ会議ですね。今日も長い会議に出席させられそうです。
    （啊，马上要开会了。今天可能又被迫参加长会议。）
  • 森：仕方ないですね。会社員はよくさせられるものです。
    （没办法啊。公司职员就是经常被迫做这做那的。）
  • 李：そうですね。でも、させられることが多いほど、勉強になりますね。
    （是啊。不过，被迫做的事情越多，越能学到东西呢。）
  • 小野：前向きに考えるのはいいことですね。私もそうします。
    （积极地思考是好事呢。我也要那样。）
  • 森：では、会議に行きましょう。今日はみんなで頑張らされましょう！
    （那我们去开会吧。今天大家一起被迫加油吧！）

四、笔记总结

核心重点

本课重点掌握使役被动形的变形规则，以及被迫做某事的三种主要句型。这是日语动词形态中最复杂的一种，但也是表达“不情愿”时最常用的形式。

⚠️ 终极易错提醒

  1. 五段动词的使役被动有省略形：

    • 完整形：飲ませられる（书面、正式）
    • 省略形：飲まされる（口语常用）
    • 两种都正确！初学者可能觉得完整形太长，口语中多用省略形。

  2. 「する」的使役被动是「させられる」，不是「させれる」：

    • ✅ 勉強させられた
    • ❌ 勉強させれた（错误）

  3. 「来る」的使役被动是「こさせられる」，不是「きさせられる」：

    • ✅ 来させられた（こさせられた）
    • ❌ 来させられた（きさせられた）（错误读音）

  4. 使役被动形 ≠ 被动形+使役形：

    • 使役被动形是一个整体形态，不是被动形和使役形的简单叠加。
    • ✅ 飲ませられる（使役被动）
    • ❌ 飲ませれる（缺失「ら」的不规范口语，虽有人用但不标准）

  5. 使役被动句的主语是“被迫者”，不是“施加者”：

    • ✅ 私は友達にコーヒーを飲ませられた。（我被朋友迫喝了咖啡。——主语是“我”）
    • ❌ 友達は私にコーヒーを飲ませられた。（朋友被我迫喝了咖啡。——意思反了）

  6. 「～させられる」与「～させてください」的区别：

    • ～させられる：被迫做某事（被动）
    • ～させてください：请让我做某事（礼貌请求）
    • 例：コーヒーを飲ませられました。（被迫喝了咖啡。）
    • 例：コーヒーを飲ませてください。（请让我喝咖啡。）

  7. 使役被动形在口语中的使用频率：

    • 日常口语中，使役被动形非常常用，尤其是表达“被迫做不情愿的事”时。
    • 例：待たされた。（被迫等了。）——比「待たせられた」更口语化。
