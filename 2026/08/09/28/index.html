⚠️ 单词辨析

  • 旅行（りょこう） vs 観光（かんこう）：「旅行」是广义的“旅行”；「観光」特指“以游览景点为目的的观光旅游”。
  • 泊まる（自动词） vs 泊める（他动词）：ホテルに泊まる（住在酒店）/ 客を泊める（留宿客人）。

二、语法

语法① ～ています（表示习惯 / 职业 / 长期状态）

在第14课和第27课中我们学过「～ています」表示正在进行和结果状态。第28课学习它的第三种用法——表示长期反复的习惯或职业/身份。

用法：接在动作性动词（持续性动词）后面，配合表示频率的时间词（毎日、毎年、最近等），表示长期养成的习惯或从事的工作。

例句：

  • 私は毎日ジョギングをしています。（我每天慢跑。）——习惯
  • 森さんは新聞を読んでいます。（森先生在读报纸。）——进行中 VS
  • 森さんは毎朝新聞を読んでいます。（森先生每天早晨读报纸。）——习惯

职业/长期状态的用法：

  • 私は大学で日本語を教えています。（我在大学教日语。）——职业
  • 兄は東京で働いています。（哥哥在东京工作。）——长期状态
  • 彼女は結婚しています。（她结婚了。）——结果状态（瞬间动词）

💡 如何区分三种用法？

用法 动词类型 时间词标志 例句
正在进行 持续性动词 今、現在 今、本を読んでいます。
结果状态 瞬间动词 无（或“もう”“まだ”） 窓が開いています。
习惯/职业 持续性动词 毎日、毎朝、最近、毎年 毎朝、走っています。

语法② ～てしまいました（做完某事 / 遗憾、后悔）

「～てしまう」有两种含义，根据语境判断：

含义 说明 例句
① 动作的完成 表示“全部做完、彻底完成” この本を読んでしまいました。（这本书读完了。）
② 遗憾/后悔 表示“做了不该做的事”或“发生了不好的结果” 財布を忘れてしまいました。（把钱包忘带了。——糟糕！）

口语缩略形式（非常常用）：

正式形 口语缩略形
～てしまいました → ～ちゃいました
～てしまった → ～ちゃった
～でしまいました → ～じゃいました
～でしまった → ～じゃった

例句：

  • 宿題を忘れてしまいました。（忘了作业。——遗憾）
  • ケーキを全部食べてしまいました。（把蛋糕全吃完了。——完成/遗憾都可能）
  • 大切な書類を捨ててしまいました。（把重要文件扔掉了。——糟糕！）
  • 口语：忘れちゃった！ / 食べちゃった！

语法③ ～ておきます（事先做好某事）

表示事先做好某种准备或有意地保持某种状态，以便将来使用。

  • 接续方式：动词て形 + おきます
  • 口语缩略：～ておく → ～とく（例：買っておく → 買っとく）

例句：

  • 旅行の前に、切符を予約しておきます。（旅行之前，先预订好票。）
  • お客さんが来る前に、部屋を掃除しておきます。（客人来之前，先把房间打扫好。）
  • 後で見るから、ビデオを録画しておいてください。（因为以后要看，请先把录像录好。）
  • 口语：明日の資料を用意しとくね。（我把明天的资料先准备好。）

🚨 「～ておく」vs「～てある」的区别：

语法 含义 主语 例句
～ておく 人为事先准备（动作主体明确） 人（动作主体） 私が窓を開けておきました。（我事先把窗户打开了。）
～てある 人为结果的存续（强调状态） 物/状态 窓が開けてあります。（窗户开着。——某人事先打开的）

核心区别：

  • 「ておく」强调“事先做了”这个动作本身。
  • 「てある」强调“现在处于某种被处理过的状态”。

三、课文（完整版）

基本课文（句型示例）

  1. 私は京都へ行っています。
    （我去京都了。 / 我正在去京都的路上。 / 我去了京都（现在还在那里）。——根据语境，此处表示“去了京都（出差/旅行，现在在那里）”）

  2. この本を読んでしまいました。
    （这本书读完了。）

  3. 切符を予約しておきます。
    （我先预订好票。）

  4. 毎朝、新聞を読んでいます。
    （我每天早上读报纸。）

基本课文 会话（A-D）

A

  • 森さんは今どこにいますか。
  • 京都へ行っています。

B

  • 宿題はもう終わりましたか。
  • はい、終わってしまいました。

C

  • 旅行の前に、何をしておきますか。
  • ホテルを予約しておきます。

D

  • 毎朝何をしていますか。
  • ラジオを聞いています。

应用课文（完整长篇对话）

场景：森接到了去京都出差的任务，小李正在帮他确认各种安排。他们聊起了准备工作、行程以及以往的出差习惯。

（公司办公室里）

  • 李：森さん、来月の出張の準備はどうですか。
    （森先生，下个月出差的准备怎么样了？）
  • 森：ええ、だいたい終わりました。今、新幹線のチケットを予約しています。
    （嗯，大体上结束了。现在正在预订新干线的票。）

（小李确认具体安排）

  • 李：京都にはどのぐらい滞在する予定ですか。
    （计划在京都待多久？）
  • 森：一週間ぐらいです。ホテルはもう予約してあります。
    （大约一周。酒店已经预订好了。）

（森分享自己的习惯）

  • 李：森さんは、出張の前にいつも何をしていますか。
    （森先生出差前总是做些什么呢？）
  • 森：そうですね。まず、現地の地図を買っておきます。そして、行く前に、インターネットで観光情報を調べておきます。
    （嗯。首先，我会事先买好当地的地图。然后，在去之前，先在网上查好旅游信息。）
  • 李：へえ、いつも準備がいいですね。
    （哎，你总是准备得很充分啊。）

（聊起以前去京都的经历）

  • 李：森さんは、京都へは初めてですか。
    （森先生，你是第一次去京都吗？）
  • 森：いいえ、3年前に行ったことがあります。その時、案内してもらった友達が京都に住んでいます。
    （不，3年前去过一次。那时，给我带路的朋友住在京都。）
  • 李：ああ、そうなんですか。今回も会う予定ですか。
    （啊，是这样啊。这次也打算见面吗？）
  • 森：ええ。先週、メールで連絡しておきました。
    （嗯。上周已经发邮件联系过了。）

（出发前一天）

  • 李：明日の出発は何時ですか。
    （明天几点出发？）
  • 森：朝の7時です。
    （早上7点。）
  • 李：じゃあ、今夜は早く寝ておいてくださいね。
    （那今晚请早点睡吧。）
  • 森：はい、ありがとうございます。お土産を買ってきますね。
    （好的，谢谢。我会买特产回来的。）
  • 李：ぜひ楽しんできてください！
    （请一定好好享受！）

四、笔记总结

核心重点

本课重点掌握三个表达：

  1. 「～ています」的习惯/职业用法——与“正在进行”“结果状态”区分开。
  2. 「～てしまいました」——记住口语缩略「～ちゃった」更常用。
  3. 「～ておきます」——记住与「～てあります」的区别。

综合修饰规则速查表

语法点 接续方式 含义 例句
～ています（習慣） 持续性动て形 + いる 长期习惯/职业 毎朝走っています
～ています（進行） 持续性动て形 + いる 正在做 今読んでいます
～ています（結果） 瞬间动て形 + いる 状态存续 窓が開いています
～てしまいました Vて形 + しまう 完了/遗憾 読んでしまいました
～てしまいました（口語） Vて形 + ちゃう/じゃう 同上（口语） 読んじゃいました
～ておきます Vて形 + おく 事先准备 予約しておきます
～ておきます（口語） Vて形 + とく 事先准备（口语） 予約しときます

⚠️ 终极易错提醒

  1. 「～ています」的三种用法混淆：判断关键词——看到「今」是进行，看到「毎日/毎朝」是习惯，看到「もう/まだ」+瞬间动词是结果状态。
  2. 「～てしまった」的语气：不一定都是“遗憾”，有时只是表示“全部做完”（中性），具体含义需要根据语境判断。
    • ✅ 仕事を終わってしまった。（工作做完了。——中性）
    • ✅ 鍵をなくしてしまった。（把钥匙弄丢了。——遗憾）
  3. 「～ておく」与「～てある」：
    • 私は窓を開けておきました。（我事先开了窗。——强调我做了这个动作）
    • 窓が開けてあります。（窗开着。——强调窗户现在处于打开的状态）
  4. 口语缩略不要乱用：在正式场合（如写邮件、面试）请使用完整形「～てしまいました」「～ておきます」，日常口语中可以用「～ちゃった」「～とく」。
