⚠️ 单词辨析

  • 消える（自动词） vs 消す（他动词）：火が消える（火灭了） / 火を消す（把火熄灭）。注意自动词与他动词的区分。
  • 倒れる（自动词） vs 倒す（他动词）：木が倒れる（树倒了） / 木を倒す（把树放倒）。

二、语法

语法① ～時（在……的时候）

表示“做某事的时候”或“某个时间点”，接续方式取决于前面的词性以及主句和从句的时间先后关系。

接续规则：

前面的词类 时态 接续形式 说明
动词 基本形 + 時 日本へ行く時、この本を買いました。 表示去之前或去的同时买（动作发生在去之前）
动词 た形 + 時 日本へ行った時、この本を買いました。 表示去了之后买（动作发生在到达之后）
一类形容词（い形） 基本形 + 時 若い時、よく旅行しました。 年轻的时候（过去状态）
二类形容词（な形） 词干 + な + 時 元気な時、働きます。 精神好的时候（状态）
名词 名词 + の + 時 子供の時、大きな地震がありました。 孩子的时候

核心区别（动词时态）：

  • 基本形 + 時：后项动作发生在前项动作之前或同时。
    • 例：起きる時、窓を開けます。（起床的时候开窗——先起床，同时或紧接着开窗？实际上“起床时”表示准备起或刚起。确切地说，基本形表未完成，动作后项先于或同时于前项。）
    • 更准确理解：基本形表“要做……的时候”，た形表“做了……之后的时候”。
    • 例：食事をする時、「いただきます」と言います。（吃饭前说“我开动了”。）
    • 例：食事をした時、「ごちそうさま」と言います。（吃完饭后说“多谢款待”。）

例句：

  • 子供の時、大きな地震がありました。（小时候，发生过大地震。）
  • 日本へ行く時、日本語を勉強しました。（去日本之前，学了日语。）
  • 日本へ行った時、いろいろな所を訪ねました。（去了日本之后，参观了各种地方。）

语法② ～ながら（一边……一边……）

表示两个动作同时进行。主要动作放在句尾，次要动作接「ながら」。

  • 接续方式：动词的ます形去掉「ます」 + ながら
  • 例：見る → 見ながら / 聞く → 聞きながら

例句：

  • 音楽を聞きながら、勉強します。（一边听音乐一边学习。）
  • コーヒーを飲みながら、新聞を読みます。（一边喝咖啡一边看报纸。）
  • 歩きながら、スマホを見ないでください。（请不要一边走路一边看手机。）

🚨 注意：

  • 「ながら」前后的动作必须是同一主语。
  • 后面的动作是主要动作，前面的动作是伴随状态。

语法③ ～ています（表示结果状态 / 长期习惯 / 职业）

「～ています」除了表示正在进行（第14课）之外，还有以下几种用法：

用法 含义 例句
正在进行 动作正在持续中 今、本を読んでいます。（正在看书。）
结果状态 动作完成后留下的状态 窓が開いています。（窗户开着。）
彼は結婚しています。（他结婚了。）
长期习惯 / 职业 反复进行的习惯性动作 毎朝ジョギングをしています。（每天早上慢跑。）
大学で日本語を教えています。（在大学教日语。）

如何区分？

  • 接持续性动词（如：読む、書く、食べる）→ 表示正在进行。
  • 接瞬间动词（如：開く、結婚する、消える）→ 表示结果状态。
  • 接表示习惯或职业的动词 + 频率副词（毎日、毎朝等）→ 表示习惯/职业。

例句：

  • この家具はもう壊れています。（这个家具已经坏了。）——结果状态
  • 私はあの会社で働いています。（我在那家公司工作。）——长期职业
  • 電気が消えています。（灯关着。）——结果状态

三、课文（完整版）

基本课文（句型示例）

  1. 子供の時、大きな地震がありました。
    （小时候，发生过大地震。）

  2. 日本へ行く時、この本を買いました。
    （去日本之前，买了这本书。）

  3. 音楽を聞きながら、勉強します。
    （一边听音乐一边学习。）

  4. 窓が開いています。
    （窗户开着。）

基本课文 会话（A-D）

A

  • 子供の時、どこに住んでいましたか。
  • 大阪に住んでいました。

B

  • 日本へ行く時、何を買いましたか。
  • お土産をたくさん買いました。

C

  • 毎朝、何をしていますか。
  • ジョギングをしながら、日本語のCDを聞いています。

D

  • 窓が開いていますね。
  • あっ、すみません。閉めます。

应用课文（完整长篇对话）

场景：森、李、小野在公司休息室，电视里正在播放关于防灾的新闻，大家聊起了过去的经历。

（看着电视新闻）

  • 小野：日本では、子供の時から避難訓練をします。
    （在日本，从小时候起就进行避难训练。）
  • 李：そうですか。中国でも最近はよくやっていますね。
    （是吗。中国最近也经常做呢。）

（森陷入回忆）

  • 森：そういえば、私が子供の時、大きな地震がありました。
    （说起来，我小时候发生过大地震。）
  • 李：えっ、そうですか。どこでですか。
    （哎，是吗。在哪里？）
  • 森：大阪です。あの時、私は小学校に入る時でした。
    （在大阪。那时，我正要上小学。）
  • 小野：どのぐらい揺れましたか。
    （摇晃了多久？）
  • 森：かなり長く続きました。突然、家具が倒れる音を聞きながら、怖くて泣いていました。
    （持续了相当长的时间。突然，我一边听着家具倒下的声音，一边害怕得哭了起来。）

（李继续追问）

  • 李：大変でしたね。ご家族は大丈夫でしたか。
    （真是不容易啊。你的家人都没事吧？）
  • 森：ええ。幸い、みんな元気でした。でも、家の窓ガラスが割れていました。
    （嗯。幸好大家都平安无事。但是，家里的窗户玻璃碎了。）

（小野分享自己的经验）

  • 小野：私も子供の時、小さな地震がありました。怖かったです。
    （我小时候也发生过小地震。很害怕。）
  • 森：今は、何か準備していますか。
    （现在有做什么准备吗？）
  • 小野：はい。いつ地震が起きるかもしれませんから、机のそばに水と非常食を置いています。
    （是的。因为可能随时会发生地震，所以我在桌子旁边放了水和应急食品。）
  • 李：私も防災グッズを買おうと思っています。
    （我也打算买防灾用品。）
  • 森：そうですね。備えるのが一番大切ですね。
    （是啊。做准备是最重要的。）

四、笔记总结

核心重点

本课重点掌握三个表达：

  1. 「～時」：注意动词基本形（未发生）和た形（已发生）的区别。
  2. 「～ながら」：记住主语必须一致，且主要动作在后。
  3. 「～ています」：区分“进行中”、“结果状态”和“长期习惯”。

综合修饰规则速查表

语法点 接续方式 例句
～時（名词） 名词 + の + 時 子供の時、地震があった
～時（动・基本形） 动基本形 + 時 日本へ行く時、買う（去之前买）
～時（动・た形） 动た形 + 時 日本へ行った時、買う（去之后买）
～時（形1） 形1基本形 + 時 若い時、よく遊んだ
～時（形2） 形2词干 + な + 時 静かな時、勉強する
～ながら V（ます形去ます） + ながら 音楽を聞きながら、走る
～ています（進行） 持续性动词て形 + いる 食べています
～ています（結果） 瞬间动词て形 + いる 開いています / 結婚しています
～ています（習慣） 动作性动词て形 + いる + 频率词 毎朝走っています

⚠️ 终极易错提醒

  1. 「～時」的时态陷阱：主句是过去式时，从句用基本形还是た形取决于时间先后，而不是主句的时态。
    • ✅ 日本へ行く時、買いました。（去之前买了。）
    • ✅ 日本へ行った時、買いました。（去之后买了。）
  2. 「ながら」的主语：前后必须是同一个人。✗ 私が歌いながら、彼が踊った。（错误，应为两个句子）
  3. 「～ています」的自动词/他动词：接自动词时多表示客观结果状态（窓が開いている），接他动词+てある表示人为结果（窓が開けてある），注意区分第24课内容。
