⚠️ 单词辨析

  • 泊まる vs 住む：泊まる 表示短暂停留（住酒店）；住む 表示长久居住（定居）。
  • 大きな / 小さな：属于连体词，只能直接修饰名词，不能用于结句（× この建物は大きなです）。

二、语法

语法① 动词（简体形）+ 名词 / 动词小句（简体形）+ 名词

动词修饰名词时，统一使用简体形（即“普通形”）：

  • 表示习惯或将来的动作 → 动词基本形（辞书形）
  • 表示动作已完成 → 动词た形
  • 表示正在进行的动作/状态 → 动词ている形

例句：

  • これは明日会議で使う資料です。（这是明天会议要用的资料。）
  • あれは森さんが今夜泊まるホテルです。（那是森先生今晚要入住的宾馆。）
  • 倒産した会社です。（那是倒闭的公司。）
  • 今走っているバスは三環路を通ります。（现在正在行驶的公交车经过三环路。）

🚨 三大铁则：

  1. 名词前绝对不能用敬体（× 使います資料）
  2. 修饰名词时不加「の」（× 使うの資料）
  3. 小句中的主语用「が」而非「は」（例：森さんが買った本）

语法② 动词小句（简体形）+ 名词 作主语

动词修饰名词形成的名词短语可以直接作为句子的主语。

  • 私が明日乗る飛行機は中国航空です。（我明天乘坐的飞机是中国航空公司的。）
  • 小野さんが作った料理はおいしいです。（小野女士做的菜很好吃。）
  • 交通量が一番多い道路は三環路です。（交通流量最大的公路是三环路。）

语法③ 动词小句（简体形）+ 名词 作宾语/补语

同样，该结构也可以充当宾语或补语成分。

  • 中国で買ったCDを友達に貸しました。（我把在中国买的CD借给朋友了。）
  • 中国に転勤した友達に手紙を書きます。（我给调到中国工作的朋友写信。）
  • 知らない人から手紙が来ました。（一个不认识的人给我来了信。）

语法④ 形容词 / 形容动词 / 名词 修饰名词的规则

修饰类型 变化规则 示例
一类形容词（い形） 基本形直接 + 名词 暖かい国 / 白い建物
二类形容词（な形） 词干 + 「な」 + 名词 操作が簡単なパソコン / 好きな人
名词 名词 + 「の」 + 名词 大学の先生 / 自動車の部品

三、课文（完整版）

基本课文（句型示例）

  1. これは明日会議で使う資料です。
    （这是明天会议要用的资料。）

  2. 私は明日乗る飛行機は中国航空です。
    （我明天乘坐的飞机是中国航空公司的。）

  3. 中国で買ったCDを友達に貸しました。
    （我把在中国买的CD借给朋友了。）

  4. 操作が簡単なパソコンが欲しいです。
    （我想要操作简单的个人电脑。）

基本课文 会话（A-D）

A

  • 李さん、この人は誰ですか。
  • その人は中国でとても人気がある女優です。

B

  • あの窓のところにいる人は誰ですか。
  • あれは受付の戴さんですよ。

C

  • 何をしているんですか。
  • 昨日李さんにもらった本を読んでいます。

D

  • この会社で歌が一番上手な人は誰ですか。
  • 森さんだと思います。

应用课文（完整长篇对话）

场景：森健太郎到北京的那天，小李和北京分公司的职员马国祥去机场迎接。寒暄后，由小马开车，三人前往市内的宾馆。

（在机场出来上了车）

  • 森：今日泊まるホテルは天安飯店ですね。
    （今天入住的宾馆是天安饭店，对吧。）
  • 李：はい。まず一ヶ月ぐらいホテルに泊まって、ゆっくり住まいを探してください。
    （是的。请你先在宾馆住一个月左右，慢慢找住处吧。）

（汽车上了高速公路）

  • 森：この道はまっすぐですね。
    （这条路真直啊。）
  • 马：これは空港と北京市街を結ぶ高速道路で、市街まで約30分ぐらいです。
    （这是连接机场和北京市区的高速公路，到市内大约要30分钟左右。）

（车内响起日语歌曲）

  • 森：あっ、日本の歌ですね。
    （哎，这是日本歌啊。）
  • 马：ええ、日本の友達にもらったCDです。
    （是的，日本朋友送给我的CD。）
  • 森：日本歌曲が好きですか。
    （你喜欢日本歌吗？）
  • 马：ええ、とても好きです。中国には日本歌曲が好きな人がたくさんいます。
    （嗯，非常喜欢。中国有很多喜欢日本歌的人。）

（森指着右侧前方的大楼）

  • 森：あの白い建物は何ですか。
    （那座白色的大楼是什么？）
  • 李：あれは最近建てた建物です。馬さん、何という建物か知っていますか。
    （那是最近盖好的大楼。小马，你知道那是什么楼吗？）
  • 马：ああ、あれは自動車の部品工場です。
    （啊，那是汽车零件制造厂。）

（进入三环后开始堵车）

  • 森：車が多くなりましたね。
    （车多起来了啊。）
  • 马：そうですね。今走っているこの道は三環路で、この辺はよく渋滞します。
    （是啊。现在走的这条路是三环路，这一带经常堵车。）
  • 李：三環路は北京で交通量が一番多い道路ですから。
    （因为三环路在北京是交通流量最大的公路。）

四、笔记总结

核心重点

本课最核心的语法就是 “动词（简体形）修饰名词”，中文里相当于加一个“的”字。例如：

“用的资料” = 使う資料
“买的CD” = 買ったCD

综合修饰规则速查表

要修饰名词的词类 连接方式 例句
动词 简体形 + 名 明日使う資料
一类形容词（い形） 基本形 + 名 白い建物
二类形容词（な形） 词干 + な + 名 簡単な操作
名词 名词 + の + 名 空港の案内

⚠️ 终极易错提醒

  1. 不敬体：修饰名词时永远不要用「ます・ました」形（✗ 使います資料）。
  2. 不の：动词修饰名词直接粘上去，中间不要加「の」（✗ 使うの資料）。
  3. 不用は：修饰句中的主语一律使用「が」（✓ 森さんが買った本）。
  4. 连体词结句：「大きな」「小さな」是连体词，绝对不能放在句尾（✗ この建物は大きなです）。
